# 집중 세션 연동

서버 `feature/focus-session` 브랜치의 `openapi/openapi.json`이 계약이다. 집중 세션 생성·완료·조회와 활동 레코드의 선택적인 `focusSessionId`를 생성 클라이언트에 추가했다.

- 서버에 세션을 생성한 후 타이머를 시작한다. 재시도에는 동일 UUID·시작 시각·목표를 보낸다.
- 진행 중인 관찰의 시각으로 세션 연결을 판단한다. 브라우저 문맥 조회가 늦어져 일시중지 후 도착한 관찰도 원래 관찰 시각의 세션에 연결한다. 일시중지 중 관찰은 세션에 연결하지 않는다.
- 종료 시 작업 시간을 고정한다. 라벨을 선택해 완료하면 서버에 저장하고 다음 세션은 같은 활성 라벨을 이어서 사용한다.
- 응답 유실 가능성이 있는 완료 재시도는 같은 내용으로 전송한다. 입력을 보존하고 성공 전까지 새 세션을 시작하지 않는다.
- 날짜별 완료 기록은 계정 시간대의 시작 날짜 기준이다. 지난 날짜 조회 및 설명 펼치기를 지원한다. 날짜를 빠르게 바꿔도 오래된 응답은 현재 목록을 덮지 않는다.
- 로그아웃이나 작업 화면 소유 계정 변경 후 늦게 도착한 시작 응답은 활동 수집기에 연결하지 않는다.

앱 종료 후 진행 중 타이머 복구는 지원하지 않는다. 완료한 기록은 서버에서 다시 조회한다. 개발 서버에는 새 마이그레이션을 적용해야 하며, 기존 서버 프로세스가 새 API를 제공하지 않으면 새 클라이언트에서 세션을 시작할 수 없다.

## 계약 재생성

macOS 저장소에서 다음 명령을 실행한다. 실제 서버 checkout 경로를 사용한다.

```sh
MOSEMO_SERVER_OPENAPI_SNAPSHOT=/path/to/mosemo-server/openapi/openapi.json ./scripts/update_openapi.sh
```

## 연동 검증

서버 저장소에서 Docker와 전체 Xcode가 있는 환경에서 실행한다.

```sh
uv run python scripts/verify_focus_session_client.py --client-root /path/to/mosemo-macos
```

이 검증은 임시 PostgreSQL과 테스트 계정·기기·라벨, 로컬 API를 생성한다. 실제 Swift URLSession 클라이언트로 생성, 활동 저장, 완료, 재전송, 날짜별 조회를 수행하고 DB 외래키를 직접 확인한다. 기존 앱의 인증정보나 개발 DB는 사용하지 않는다. 일반 `swift test`에서는 이 환경이 필요한 테스트를 건너뛰며 위 명령으로 별도 실행한다.

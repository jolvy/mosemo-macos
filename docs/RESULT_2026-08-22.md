# Collector Spike Result — 2026-08-22

이 문서는 구현 중 실제로 실행해 확인한 결과만 기록한다. 사용자 상호작용이
필요하거나 장시간이 걸려 수행하지 않은 검증은 통과로 간주하지 않는다.

진단 화면의 메모리 ring buffer에만 노출하는 임시 예외다. 이 값은 안전 이벤트,
안전 진단 복사, 파일, console, 서버에는 넣지 않는다. 실제 MVP로 진행할 때는
이 개발 진단 예외를 제거하거나 명시적인 개발 빌드에서만 활성화해야 한다.

## 판정

현재 판정은 **Conditional Go**다.

네이티브 macOS 앱, Chrome Apple Events adapter, 권한 요청 UI, 세션 경계,
메모리 ring buffer, 복귀 adapter와 순수 로직 테스트는 구현·빌드됐다. 따라서
이 방식의 가능성을 더 측정할 가치는 있다. 그러나 핵심 합격 기준인 Chrome 실제
전환 감지, 복귀, 100회 누락·지연, 개인정보 runtime 검사, 8시간 CPU·메모리는
아직 측정하지 않았다. 이 결과 없이 CatchHabit MVP 구현으로 확장하는 Go 판정을
내려서는 안 된다.

Go로 바꾸기 위한 조건:

1. active 집중 세션에서 100회 전환 CSV를 완성하고 누락 1회 이하, p95 2초
   이하를 확인한다.
2. 세션 밖·의도된 휴식·종료 후 이벤트 증가가 각각 0인지 확인한다.
3. 시크릿과 안전 진단 snapshot·runtime output에서 금지 데이터가 0인지 확인한다.
4. 지원 가능한 일반 앱·창·Chrome 탭 복귀의 attempt와 result를 확인한다.
5. 8시간 실행에서 치명적 중단 0, 평균 CPU 3% 이하, 최대 RSS 200MB 이하를
   확인한다.
6. MVP 전환 전에 원시 제목·전체 URL 진단 예외를 제거하거나 개발 빌드로만
   제한한다.
